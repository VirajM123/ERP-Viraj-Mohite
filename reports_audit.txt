- Reports with strong filters: Most catalog, stock, sales, purchase, GST and financial reports.
- P0 financial, catalog, stock-movement and audit-trail endpoints now reject malformed/impossible dates and reversed ranges instead of silently returning misleading or empty results.
- Reports with limited/no filter UI:
  Permission Audit Report - optional user and module searches; blank searches show all permission rows.
  Credit Control Report - optional account code/name search; blank search shows all accounts.
  Current Stock Report - deliberately current balance, but includes company/godown/status/expiry/order filters.
  Current master-list reports - use search and active-record status instead of date filters.
- There are no reports in the audited report-specific code that are exclusively fed by a static array or Math.random().
- CommonReportGrid has local column visibility and column filters after data generation; these are result filtering,
  not fake report data.
- CatalogReport also has local search, column sorting and pagination after generation; the generated rows come from
  /api/p0/reports/catalog/:report.
