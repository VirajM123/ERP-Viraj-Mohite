REPORT-WISE DATA AND MODIFICATION AUDIT
=======================================
Review date: 18 November 2026
Scope: active src/ and backend/ source, using REPORT_DATA_FILTER_AUDIT.txt as the detailed evidence base; archived checkouts excluded.

STATUS KEY
DB / VERIFY: API/database-backed source path; accuracy against the actual firm's database has not been proven. No report is certified correct without live reconciliation.
DB / FIX: database-backed path with a confirmed source-code defect below.
DEMO FILTER: report output is API-backed but demo values can appear in filters.

No active generated report was found to intentionally use fixed sample result rows. All Product Wise Sales retains a dormant demo generator and demo filter fallback. Hardcoded titles and column definitions are UI metadata, not transaction data. Some missing backend models can yield a successful empty result; change these to explicit source-unavailable errors.

Columns and filters below are recommendations, not a claim that each is missing or exists in the data model. Add only relevant fields after checking existing output and availability; do not fabricate values. As-of filters require historical calculations, not merely filtering current balances.
